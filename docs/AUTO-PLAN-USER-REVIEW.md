# Auto-Plan v7.5: Prüf- und Bestätigungsablauf

1. Auto-Plan berechnet zunächst eine vollständige Null-Rot-Variante.
2. Falls erforderlich, folgt eine vertiefte Null-Rot-Suche.
3. Nur wenn beide Suchstufen keine Komplettbelegung ergeben, wird eine Minimal-Rot-Variante berechnet.
4. Während des Laufs zeigt das Observatory Arbeitsmenge, Portfolio und Qualitätsgewinne getrennt. Der Gesamtwert erreicht erst nach Abschluss aller relevanten Arbeitsstränge 100 Prozent.
5. Die kommentierte Laufspur nennt reale Engpässe, Suchmengen, Perfektionsrunden und Verbesserungen. Sie ist eine Erklärung beobachteter Arbeit, keine künstliche Restzeitprognose.
6. Die Ergebnisansicht zeigt sämtliche konkreten BD/HG-Zuteilungen und die vollständige Belastungsstatistik in einem scrollbaren Prüfbereich.
7. Jede rote Zuteilung wird mit Datum, Rolle, Person, Bestätigungstyp und sämtlichen Regelgründen aufgeführt.
8. Ohne ausdrückliche Bestätigung bleibt die Übernahme gesperrt.
9. Vor dem Schreiben werden Fingerprint, freie Felder und sämtliche Regeln erneut geprüft.
10. Jede bestätigte rote Zelle wird einzeln im Override-Protokoll dokumentiert.

**Abbruch und Bewegung:** „Abbrechen“ beendet auch die kurze Ergebnisüberleitung sicher; ein spätes Ergebnis öffnet den Dialog nicht erneut. Bei reduzierter Bewegung zeichnet die Laufgrafik nur auf echte Zustandsänderungen. Wird die erweiterte Tooltip-Funktion in den App-Einstellungen deaktiviert, schließt ein sichtbarer Hinweis sofort.
